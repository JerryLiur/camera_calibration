# Spike 标定工作台界面

本轮优化针对 Qt Widgets 主程序，保留采集、求解、独立验证、转台关系和工程配置流程。

## 布局与视觉

- 白色工程栏、蓝灰色工作区和深蓝图像取景器。工程标定状态与设备连接状态分别显示。
- 五个页签保留原顺序。`Alt+1` 至 `Alt+5` 切换页签，`Ctrl+N` 新建工程，`F5` 刷新工程。
- 采集页优先展示图像，右侧观测及导入区域独立滚动；Spike/DAT 高级参数默认折叠，展开后可滚动访问全部配置。
- 设备页按连接、采集、预览分组。预览保持图像比例，随窗口缩放；帧格式与采集参数可展开。
- 内参矩阵三列自适应，诊断 JSON 默认折叠。工程配置长说明换行，避免横向撑宽。
- 共用样式位于 `src/ui/UiHelpers.cpp`，包含按钮主次、焦点、禁用态、表单、表格和滚动条。字段保留原数据精度。

设计依据：ui-ux-pro-max 的 Data-Dense Dashboard 搜索结果和通用桌面可访问性指南。Qt Widgets 不在技能专用栈列表内；未套用其他框架的实现规则。

## 图标

主图标采用镜头圆环、中心标靶和四角对准框，深蓝底、蓝色边角、青色中心。PNG 与多尺寸 Windows ICO 位于 `resources/`，窗口与 EXE 都嵌入图标。生成方式和提示词见 `resources/ICON.md`。

下拉箭头与复选勾选标记保留 SVG 源；运行时使用其 PNG/@2x 转码，不额外要求 QtSvg。

## 检查

`spike_uitest --screenshots <目录>` 在临时合成工程中生成两种尺寸（1440×940、1100×720）的空态、五页及高级参数展开态截图。测试覆盖横向溢出、矩阵文本、键盘展开/折叠、无工程时导出禁用，并保留既有业务回归。截图中的合成数据不是实机精度证据。
